Overview
########
########

The client protocol is used for connection between server and client.
It performs authentication and establishes encrypted connection.
All data is bitwise xor-ed with a stream of pseudo-random numbers (scrambled)
in order to make it harder for an eavesdropper to identify and parse the data.

Handshake
#########
#########

Handshake is the initial part of the client protocol.
It is used for authentication via challenge-response
scheme and establishing an encrypted channel.

client                                                     server
   Syn
             | scrambler init | name size | name |
                ------------------------------>

   SynAck
    | scrambler init | timestamp | encrypted challenge (key1) |
                <------------------------------

   Ack
                | encrypted challenge (key2) |
                ------------------------------>

"scrambler init":  byte;
"name size": 32-bit integer;
"name": an array of characters with length equal to "name size".
Limiting zero byte is not used.
"timestamp": a 64-bit signed integer.

Challenge has size of 64 bytes and is randomly generated by the server.
Encrypted challenge size is challenge size plus nonce and MAC size.

In case of failure any side must interrupt the session by closing the TCP
connection.

Session
#######
#######

After the handshake client and server have encrypted duplex channel for
communication. Each direction has its own session key.

Command structure:
| command id | optional payload |

Some commands may require answer from the other side. Answers have the same
structure:
| command id | optional payload |
"Command id": 32-bit integer.

Command list
############

| keep alive | timestamp |
"timestamp": a 64-bit signed intager.

This command is used when the session is idle in order to check the connection.
It is initiated by the client. When the server receives this command
it must send the same command with the same parameter as response.

| get host name |

Response:
| get host name | name length | name |

| request id |

| update id |

| add contact |

| update contact key |

| send message | message size | message data |
This command is sent by the client to send a new message.

| set message attribute | message header hash | attribute id | value |
This command is sent by the server or client to update message status.

| update message | message size | message data |
This message is sent by the server to deliver a new message.
