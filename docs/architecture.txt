Control system
--------------

Control system does not use encryption and authentication because
control port is available only via UNIX socket and is not exposed
to the network.

Command structure:
  Command id (int32)   Command data
|      shutdown      |
|   get public key   |
|      add user      | key | signature | name size (int32) | name |
|    remove user     | key |
|     list users     |
|   list banned IP   |
|       ban IP       | IP (uint32) |
|      unban IP      | IP (uint32) |

Response structure.
shutdown         | no response
get public key   | result code | public key |
add user         | result code |
remove user      | result code |
list users       | result code | user count (int32) | key | name (55 bytes) |...
list banned IP   | result code | IP 1 (uint32) | ... | IP N (uint32) |
ban IP           | result code |
unban IP         | result code |

Storage structure
-----------------

Server:
  Event sequence storage:
    storage/users/owner_name/sequence/ObjectStorage
    Entry structure: | entry type | next entry id | payload |
  Message storage:
    storage/users/owner_name/storage/peer_name/ObjectStorage
  Contact book:
    storage/users/owner_name/contacts/peer_name/peer_key
    Each file contains key properties.

Client:
  Message storage:
    storage/owner_key/storage/peer_name/ObjectStorage
    Entry structure:
    | previous message | attributes | header size | message |
  Contact book:
    storage/owner_key/contacts/peer_name/peer_key
    Each file contains key properties.

Server event sequence storage entry types
-----------------------------------------

New contact:
| NEW_CONTACT | next entry id | contact name (string) |

Contact key update:
| UPDATE_CONTACT_KEY | next entry id | contact name (string) | key |...
...| validated (uint8_t) | blocked (uint8_t) | set as default (uint8_t) |

Block contact:
| BLOCK_CONTACT | next entry id | contact name (string) | is blocked (uint8_t) |

Message:
| MESSAGE | next entry id | peer name | header hash |

Message update:
| MESSAGE_UPDATE | next entry id | peer name | header hash |...
...| attribute id | attribute value |

Delete message:
| DELETE_MESSAGE | next entry id | peer name | header hash |

Remote message update:
| REMOTE_MESSAGE_UPDATE | next entry id | message header |...
...| MAC | nonce | attribute ID | attribute value |

Configuration
-------------

Server configuration.
talkd.conf in ini format.
    RestrictedMode

    [Network]
    IPv4
    Port

    [FailBan]
    Enabled
    AllowedTries
    CooldownInterval

Client configuration.
/owner_key/talk.conf in ini format.
    [connection]
    ServerIP
    ServerPort
    ServerKey

    [voice]
    Volume
    ApplyFilter
    SilenceLevel

This file also contains key bindings.
